⚙️ Settings

←

Current room

Pre-fills the room on every new book, so a scanning session doesn't need it typed each time. Pick an existing room or name a new one. Filing a book in a different room makes that one current instead. This is remembered per device.

Rooms

Renaming a room updates every book in it.

Genres

Automatic categorization by keyword on title and author (gardening, esotericism, art, novels, comics…). Books already categorized are left untouched unless you check the box below.

Duplicates

Books sharing the same ISBN (or import identifier). Groups in red have different titles: it's almost always an ISBN error in the source data, not a real duplicate.

Cover quality

Most covers imported before the fix are 128px-wide thumbnails. This re-asks Open Library and Google Books for a bigger version of every cover narrower than the threshold, and only replaces one when a clearly wider image comes back. Books without an ISBN are skipped. It takes a few minutes — you can leave the page, the job keeps running.

    Export to Calibre

    Generates one EPUB per book (full metadata, generated cover if missing) in a directory ready to import into Calibre.
